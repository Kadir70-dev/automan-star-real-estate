# SEO launch checklist — Automan Star Real Estate

Canonical domain: https://automanstarrealty.com/

## What this branch includes

- Brand-led homepage metadata and unique metadata for buyer, off-plan, commercial, properties, about and contact pages.
- Canonical URLs, social sharing metadata, robots.txt and sitemap.xml.
- RealEstateAgent structured data with published Business Bay address and email only.
- Helpful property-buying, off-plan and commercial guidance.
- Noindex for illustrative property details, dashboard home, saved and compare screens.
- Published property detail SEO from the actual public property API, with noindex on API failures.
- Removal of internal launch placeholder copy from About and Contact.

On 24 October 2026 the custom domain content did not completely match the connected GitHub repository. The Vercel project visible to this account has no automanstarrealty.com domain association. Verify the domain's real deployment source and current Git revision before merging or deploying; this branch alone does not change the live website.

## After deployment

1. Verify robots.txt and sitemap.xml HTTP 200 on the custom domain.
2. Validate title, meta description, canonical and social metadata on every public route.
3. Validate structured data; no rich-result eligibility is promised.
4. Verify domain property in Google Search Console, submit sitemap and inspect index coverage.
5. Measure mobile/desktop Core Web Vitals: LCP, INP and CLS on the live deployment.
6. Complete and verify Google Business Profile using client-approved name, address, contact and category. Do not invent a licence number, phone, reviews or awards.
7. Add approved real property listings with original photos, accurate details and useful descriptions. No invented payments, prices or developers.
8. Track organic search clicks, enquiries and conversions in Search Console and analytics.
